# Product Context - Mestoits

## Problème résolu
La plateforme répond au besoin d'une solution immobilière complète permettant :
- La mise en relation entre propriétaires et acheteurs/locataires
- La gestion simplifiée des locations et baux
- L'accès à des données de marché (prix, estimations)
- La professionnalisation des acteurs du secteur immobilier

## Expérience utilisateur

### Parcours utilisateur principal
1. **Découverte** : Consultation des biens disponibles sur la page d'accueil
2. **Recherche** : Utilisation des filtres pour trouver le bien idéal
3. **Contact** : Prise de contact avec le propriétaire via formulaire ou messagerie
4. **Publication** : Pour les propriétaires, dépôt d'annonce en plusieurs étapes
5. **Gestion** : Suivi des biens publiés, gestion des messages, gestion locative

### Parcours professionnel
1. **Inscription** : Création de compte professionnel avec informations d'entreprise
2. **Vérification** : Upload de documents pour certification
3. **Publication** : Mise en avant des biens avec badge professionnel
4. **Gestion** : Outils avancés de gestion locative et suivi client

### Parcours locataire/propriétaire
1. **Création de bail** : Définition des conditions de location
2. **Signature** : Signature électronique du contrat
3. **Suivi** : Paiements, quittances, communication
4. **Renouvellement/Clôture** : Gestion du cycle de vie du bail

## Valeurs ajoutées
- **Gratuité** : Publication gratuite pour tous les utilisateurs
- **Transparence** : Données de prix et estimations accessibles
- **Simplicité** : Interface intuitive et processus simplifiés
- **Professionnalisme** : Certification et outils pour les professionnels
- **Efficacité** : Gestion centralisée de tous les aspects immobiliers

## Métriques de succès
- Nombre d'annonces publiées
- Taux de contact entre utilisateurs
- Nombre de baux créés
- Utilisation de l'estimation
- Taux de conversion professionnel
